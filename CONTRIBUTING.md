# Contributing to Azimuth_Elevation_Dial

Thank you for your interest in contributing to the Azimuth_Elevation_Dial project! We appreciate bug reports, feature requests, code contributions, and documentation improvements.

## Getting Started

1. Fork the repository and clone your fork.
2. Ensure you have Qt 6 and a compatible C++ compiler installed.
3. Open the project via CMake in your preferred IDE (e.g., Qt Creator).

## Making Changes

- Create a descriptive feature branch for your changes.
- Follow the existing code style and formatting conventions.
- Add or update tests where applicable (see the `tests/` directory).
- Ensure all tests pass cleanly before submitting a pull request.

## Submitting a Pull Request

1. Push your changes to your fork.
2. Open a pull request against the main branch with a clear description of the problem solved or feature added.
